# AsteroidBelt

AsteroidBelt leverages Geo-Spatial Analytics and Real-time Processing for Autonomous Decision-Making and Simulated Event Analysis.

With AsteroidBelt, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/AsteroidBelt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
